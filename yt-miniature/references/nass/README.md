# Nass Reference Photos

Drop reference photos here for AI thumbnail generation.

## Naming Convention

Name files by expression type so the skill can auto-select:

```
surprised.jpg      — eyebrows raised, mouth open
curious.jpg        — eyebrow raise, engaged eyes
confident.jpg      — slight smile, direct gaze
focused.jpg        — looking at screen, concentrated
skeptical.jpg      — one eyebrow up, slight frown
neutral.jpg        — baseline expression
```

## Requirements

- Face clearly visible, well-lit
- High resolution (min 1024px on the longest side)
- No heavy filters or processing
- Multiple angles welcome (add suffix: `curious-angle2.jpg`)
- Formats: JPG, PNG, WEBP
