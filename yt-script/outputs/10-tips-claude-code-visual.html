1
Le Context & CLAUDE.md
Le brief de ton projet. Sans ça, Claude improvise.
  • Fichier à la racine du projet — Claude le lit à chaque lancement
  • Tu y mets : qui tu es, le contexte du projet, les règles, tes préférences
  • C'est comme donner un brief à un freelance — meilleur brief = meilleur résultat
  • /init le génère automatiquement en analysant ton projet
✦

Tip 2/10
2
Les 5 commandes essentielles
Les commandes que tu dois connaître par cœur.
  • /voice — Active le mode vocal. Maintiens Espace pour parler, Claude transcrit. Pratique pour coder sans taper
  • /review — Revue complète de ton code : bugs, améliorations, bonnes pratiques. Un collègue dev qui relit ton travail
  • /clear — Efface la conversation, repart à zéro. Utile quand la session est trop longue ou que tu changes de sujet
  • /cost — Affiche le coût en dollars et tokens. Surveille ta consommation sur ton abo ou ton API
  • /help — Toutes les commandes disponibles. Le réflexe quand t'es perdu

Tip 3/10
3
Le choix du modèle
Le bon outil pour la bonne tâche. Pas toujours le plus cher.
  • Opus — Architecture complexe, bugs vicieux, réflexion stratégique
  • Sonnet — Le quotidien, 80% des tâches, rapide et pas cher
  • Haiku — Petites corrections, renommages, trucs simples
  • Tout en Opus = budget cramé. Tout en Haiku = galère assurée

Flags & modes
Des options qui changent complètement le comportement.
  • --dangerously-skip-permissions — Plus de popups de validation à chaque action
  • -r — Reprendre la dernière conversation où tu l'as laissée

Tip 5/10
5
Les Hooks
L'automatisation invisible. Configure une fois, oublie.
  • Des scripts qui se lancent automatiquement sur certaines actions
  • Exemple : linter automatique après chaque modification de fichier
  • Exemple : formatage du code à chaque sauvegarde
  • Résultat : du code propre à chaque fois, sans rien demander
✦

Tip 6/10
6
MCP Servers
Connecte Claude Code à tous tes outils. Il fait tout.
  • MCP = Model Context Protocol — un pont vers tes outils externes
  • Notion, Figma, bases de données, APIs, navigateur web...
  • Sans MCP : assistant qui code. Avec MCP : assistant qui fait tout
  • Des centaines de serveurs MCP créés par la communauté, prêts à l'emploi
Nass Riviera
Tip 7/10
7
Raccourcis clavier
Pas le plus sexy. Mais le plus utile au quotidien.
  • Escape — Annuler une génération en cours (indispensable)
  • Tab — Accepter une autocomplétion
  • Entrée — Dire "oui" sans taper "oui"
  • Petits gestes, gros gain de temps sur une journée entière
✦

Tip 8/10
8
Custom Slash Commands
Crée tes propres commandes. Tes macros IA personnelles.
  • Un fichier markdown dans .claude/commands/ = une nouvelle commande
  • /project:commit — Analyse les changements, commit avec un message propre
  • /project:review — Relit le code avant de push
  • 30 secondes pour créer, réutilisable à l'infini
Nass Riviera
Tip 9/10
9
GitHub
Ton filet de sécurité. Même si t'es pas dev.
  • Sauvegarde — Ton code est pas juste en local, il est safe dans le cloud
  • Historique — Reviens à n'importe quelle version de ton projet
  • Collaboration — Un freelance peut bosser sans envoyer des fichiers par mail
  • Claude Code s'intègre nativement : PRs, issues, reviews depuis le terminal

Tip 10/10
10
Le Workflow Idéal ⚡
Combine les 10 tips. Seul = bien. Ensemble = machine.
  • /init ton CLAUDE.md — la fondation
  • Mets le projet sur GitHub — le filet de sécurité
  • Configure hooks + custom commands — l'automatisation
  • Connecte tes MCP servers — l'écosystème
  • Choisis le bon modèle selon la tâche, /plan avant les gros chantiers
  • /compact régulièrement pour rester performant
