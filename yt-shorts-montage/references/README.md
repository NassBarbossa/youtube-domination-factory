# Ressources yt-shorts-montage

Ce dossier accueille le style de montage de Nass pour les Shorts (exemples de référence, sous-titres, rythme, effets). Tant qu'une règle n'est pas écrite ici ou dans `SKILL.md`, on ne l'invente pas : on demande à Nass.

À chaque ressource ajoutée : la citer dans la section « Ressources » du `SKILL.md`.

Ressources présentes : `motion-graphics-guide.md` (guide Damiano Caudullo adapté, bloc STYLE Editorial Grain), `motion-ressources.md` (Claude Motion Tips + laforet.dev).
